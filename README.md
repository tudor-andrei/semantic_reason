## Installation

Use the following commands to install the project and its dependencies:

```bash
uv sync
```

### Custom Installation

---
| Package                | Version  |
|------------------------|----------|
| black                  | 25.9.0   |
| isort                  | 6.1.0    |
| pandas                 | 2.3.3    |
| sentence-transformers  | 5.1.2    |

### Initialize project using UV package

```bash
uv init
(uv venv .venv; .\.venv\Scripts\activate)
```

### Install individual dependencies

```bash
uv add black 

uv add isort

uv add pandas

uv add sentence-transformers
```

## Usage

Example usage:

uv run .\semantic_reason\main.py
